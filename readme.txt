KHOJ v2 — NETLIFY-READY WEBSITE

This is a static, mobile-responsive website. No start-khoj.bat, server, build step, or backend is needed for Netlify.

DEPLOY TO NETLIFY
1. Extract this ZIP.
2. Open https://app.netlify.com/drop
3. Drag the extracted Khoj_Netlify_v2 folder (the one containing index.html) onto the page.
4. Wait for Netlify to publish the site and give you a public HTTPS URL.
5. Open that URL on your phone and test the BB84 animation, detector markers, research images, and quiz before generating a QR code.

FILES
- index.html: site markup, styling and JavaScript
- cern-map-reference.png: CERN map image used by the interactive map
- assets/: local SVG assets used by the page

NETWORK NOTES
- The main site and supplied map image are hosted by Netlify after deployment.
- Detector/research photos link to official CERN or experiment websites and need an internet connection. If an image host blocks a photo, the official page link remains available.
- The drawn fibre route is illustrative, not a surveyed cable trace.
- The map markers are approximate explanatory markers, not official coordinate data.
